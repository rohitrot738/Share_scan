# Share Scan

- Every change to the app adds an entry at the top of `app/src/main/assets/changelog.json` (`Changelog.kt`): `"version": ""`, today's date (IST), and one Hindi line per change a user would notice. First give the previous top entry the version of the release built from it (the latest GitHub release). The About sheet lists these entries, and the release workflow publishes the top one as the GitHub release notes.
- Every change a user would notice also updates the beginner's guide, `app/src/main/assets/guide/index.html` (Menu → शुरुआती गाइड, `GuideSheet`), in the same change. Something new gets its own part, or the section that covers it is rewritten, in plain Hindi for someone new to the market: where to find it, what each button and number means, the steps one by one, an example with real numbers, and the caution that goes with it. A new screen gets a screenshot in `assets/guide/img/` (360px wide JPEG), new words go in शब्दकोश and likely questions in आम सवाल, and the contents list and the Menu list stay in step. The page loads nothing from the internet and keeps the app's own fonts. `GuideAssetTest` checks that every picture it names ships with it and that every Menu entry is in it.
